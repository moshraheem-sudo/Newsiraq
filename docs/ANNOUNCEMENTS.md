## نسخة جاهزة للنشر على Telegram و Facebook

🚀 **إطلاق الإصدار الأول (v1.0.0) من مشروع: مركز أخبار العراق (Iraq News Hub)** 🇮🇶📰

يسعدنا الإعلان عن إطلاق **Iraq News Hub**، وهو مشروع برمجي متكامل ومفتوح المصدر صُمم لجمع الأخبار العراقية تلقائياً من قنوات تلغرام العامة وعرضها في منصة عربية سريعة ومستقلة!

✨ **فكرة المشروع وماذا يقدم؟**
• **تجميع تلقائي من قنوات تلغرام العامة:** يقرأ الأخبار مباشرة من صفحات العرض العام (`t.me/s/`) بلغة Python دون الحاجة إلى Bot API أو مفاتيح سرية.
• **تحديث ذكي كل 10 دقائق:** يعمل تلقائياً عبر GitHub Actions مع منع تكرار الأخبار، والاحتفاظ بالأرشيف، وتتبع المنشورات المعدلة ومتعددة الوسائط.
• **واجهة ويب عربية RTL عصرية:** متوافقة مع الكمبيوتر والهواتف وWebView، وتضم البحث الفوري، الفلترة حسب المصدر والتصنيف، تفاصيل الخبر الكاملة، ورابط المنشور الأصلي.
• **جاهز للربط مع تطبيقاتك:** يوفر واجهة بيانات `JSON` منظمة يمكن لتطبيقات أندرويد وويندوز قراءتها مباشرة عبر HTTP.
