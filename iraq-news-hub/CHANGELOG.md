# سجل التغييرات | Changelog

يتم توثيق جميع التغييرات والإصدارات البرمجية لمشروع **Iraq News Hub** في هذا الملف وفق معيار [Semantic Versioning](https://semver.org/).
ملاحظة: عمليات جلب الأخبار الدورية كل 10 دقائق تحدث البيانات في `data/news.json` فقط ولا تُنشئ إصداراً جديداً للتطبيق.

---

## [1.0.0] - 2026-11-21

### المضاف (Added)
- نظام استخراج مستقل بلغة Python (`scraper/`) يقرأ صفحات الويب العامة `https://t.me/s/<username>` فقط.
- دعم استخراج النصوص، الروابط، الصور المتعددة، الفيديوهات، معاينات الروابط، التواريخ، ورابط المنشور الأصلي.
- ملف إعدادات مرن `config/sources.json` يدعم البدء بقناتي **وكالة الأنباء العراقية (واع)** و**صابرين نيوز** مع قابلية إضافة مئات القنوات مستقبلاً.
- محرك تخزين `data/news.json` مع منع التكرار عبر `(source_username, message_id)`، الاحتفاظ بالأخبار القديمة، وتتبع التعديلات عبر `content_hash`.
- ملف مراقبة صحة المصادر `data/sources_status.json` يسجل آخر تحديث ناجح وآخر خطأ لكل قناة بشكل مستقل.
- أتمتة عبر GitHub Actions (`.github/workflows/update-news.yml`) للتشغيل كل 10 دقائق والتشغيل اليدوي ومنع التعارض (`concurrency`).
- واجهة ويب عربية RTL (`web/`) متوافقة مع الهواتف والكمبيوتر وWebView في أندرويد وويندوز، مع البحث، الفلترة، صفحة التفاصيل، وصفحة الإصدارات والمعلومات.
- نشر تلقائي على GitHub Pages مع إتاحة `/news.json` مباشرة للتطبيقات الخارجية.
- اختبارات وحدة (`tests/test_scraper.py`) ووثائق التشغيل والإطلاق والتحديثات.
